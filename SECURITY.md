# Security policy

Please report security problems privately, never in a public issue: email **security@yof.io**, or use GitHub's private vulnerability reporting on this repository. We reply within three working days.

In scope: the plugin showing or copying a secret in full, the plugin making network calls itself, a project making the plugin run a program of its own, and yof attack starting without your confirmation or against another address than the one in Settings.

Problems in the CLI itself go to the same address, or to github.com/yof-dev/yof.
